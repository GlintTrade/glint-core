# Code of conduct

We want this project to be a respectful, professional place for everyone who uses or contributes to it.

## Expected behavior

- Be respectful and constructive, in code review and in discussion.
- Assume good faith; disagree with ideas, not people.
- Keep discussions on topic and useful to others.

## Unacceptable behavior

- Harassment, insults, discriminatory or sexualized language or imagery.
- Personal attacks, trolling, or deliberately derailing discussions.
- Publishing others' private information without permission.
- Promoting scams, pump schemes or unsolicited token offers.

## Enforcement

Maintainers may edit or remove comments, commits and issues that violate this code, and may temporarily or
permanently ban contributors who do so. Report problems by X direct message to @Glint_Trade (https://x.com/Glint_Trade); reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
